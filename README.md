ey Features of the Dashboard:

* Admission Analysis: Overview of total new admissions across different academic years, from 2020 to 2022.
* Estimated School Strength: Visual representation of the estimated total student strength.
* Class-wise Admission Analysis: Admission trends from Nursery to Class 12.
* Gender Distribution: Analysis of student admissions based on gender.
* Category-wise Analysis: Comparison of admissions across different categories.
* Senior Secondary Stream Analysis: Separate analysis of Commerce, Arts, and Science streams for Classes 11 and 12.
* Interactive Filters: Each chart includes filters based on classes, gender, and categories, allowing users to explore the data according to their requirements.
* Google Maps Integration: Added the school’s location through Google Maps for easy identification.
* About the School: Included a dedicated section providing basic information about the school.
